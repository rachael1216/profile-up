# Profile Up

**个人学术网站与简历生成系统** · [English](README.md)

[云端工作室](https://profile-up-studio.beigemelon7.chatgpt.site) 当前限项目所有者访问，个人主页发布沿用此访问范围。

## 摘要

Profile Up 为个人学术网站与简历提供统一的编辑界面。用户可分别填写中英文基本信息、教育与任职经历、学术成果、项目、教学资源及相关记录，并通过排版设置生成网站和 CV。云端草稿保存完整的可编辑资料；发布时另存包含所选内容的网站快照。当前实现包括在线编辑、按账号保存草稿、个人主页发布，以及 PDF、Word、XeLaTeX 和静态网页导出。

## 已实现功能

- 基本信息及各类经历的中英双语编辑，支持照片、外部链接、条目显示控制和模块排序。
- 三种网页风格及六种 CV 版式。模板按视觉与排版风格组织；研究领域分类独立填写。
- 常用英文学术字体、思源宋体和思源黑体，以及字号、行距、纸张和照片设置。
- 登录后将草稿保存至云端。版本检查用于识别多个窗口之间的更新冲突。
- 发布个人主页至 `/p/{slug}`，支持更新和撤下。修改草稿后，已发布页面维持原版本，直至再次发布。
- 可搜索的 PDF、原生可编辑 DOCX、含字体及编译说明的 XeLaTeX 源项目、静态网站 ZIP，以及完整 JSON 备份。

## 实现与数据处理

前端使用 React 和 TypeScript；Vinext 在 Cloudflare Workers 上提供页面与 API；Cloudflare D1 分别保存草稿和发布快照。云端记录以登录账号为索引，写入接口校验身份、请求来源、记录格式与版本。浏览器本机草稿也按账号区分。

网站和 CV 使用各自的显示设置。发布与导出前，`projectProfile` 会移除隐藏条目、关闭的模块及不显示的联系方式。完整 JSON 备份包含隐藏内容，应由用户自行保管。网站访问范围由当前部署的共享设置决定。

## 本地运行与检查

需要 Node.js 22.13 或更新版本；建议使用 Node.js 24 LTS。

```bash
git clone https://github.com/rachael1216/profile-up.git
cd profile-up
npm ci
npm run build
npm run db:local
npm run dev
```

打开 `http://127.0.0.1:5173/`。本地登录使用开发身份，与生产登录及云端数据库分离。macOS 可在完成安装与数据库初始化后双击 `启动 Profile Up.command`，或运行 `npm run local:start`。

```bash
npm run typecheck
npm test
npm run test:e2e
```

检查覆盖记录校验、输出过滤、文本转义、文件导出和云端保存/发布流程。当前版本尚未开展比较性用户研究，未报告简历质量或易用性方面的实验结果。

## 适用范围

当前为研究原型。机构邮箱验证、外部账号归属验证、文献自动导入、自定义域名与协作编辑仍待实现。云端单份草稿上限为 900 KB，照片在浏览器中压缩；授课视频使用外部链接。

PDF、Word 与 XeLaTeX 的排版引擎不同，分页和字形可能存在差异。Word 使用阅读器已安装的字体，其余格式嵌入或附带可再分发字体。教育部学科目录与 ACM CCS 使用标明版本的节选，参考译名与官方原文分开标注。详见[字体与分类来源](docs/references.md)。
